# Versões

As tags do Wavern Skills identificam a versão da coleção. Cada skill mantém um changelog para mudanças em seu fluxo ou motor de análise.

A instalação ocorre diretamente pelo GitHub com `npx skills@latest add fincraft-solutions/wavern-skills`. Este repositório não publica um pacote npm próprio.
