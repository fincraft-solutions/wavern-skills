# Segurança e dados

Não publique chaves, tokens, comprovantes, arquivos de clientes ou dados pessoais em Issues, PRs ou discussões. Os exemplos do projeto são sintéticos.

Se encontrar uma vulnerabilidade que pode expor dados, use o fluxo de **Private Vulnerability Reporting** do GitHub quando habilitado no repositório. Se não estiver habilitado, não abra issue com detalhes exploráveis ou segredos; solicite um canal privado pelos meios institucionais oficiais da Fincraft.

Este repositório não oferece suporte de emergência, aconselhamento tributário ou validação de movimentações bancárias.
